Исправь баг в `files-converter` и по возможности добавь защиту от регрессии.

Сначала прочитай:
- `AGENTS.md`
- `.codex/context.md`
- `.codex/handoff.md`
- `docs/architecture.md`

Порядок работы:
1. Воспроизведи баг по конфигу, логу или команде запуска
2. Найди минимальный ответственный модуль
3. Исправь баг самым узким изменением
4. Добавь проверку от регрессии, если в коде есть практичное место для этого; если нет — запиши точный TODO в `.codex/tasks.md`
5. Если меняется долгоживущее поведение, обнови docs и добавь запись в `.codex/decisions.md`

Минимальная проверка:
- `go build ./...`
- `go test ./...`
- если баг в conversion/XML-поведении, по возможности перезапусти соответствующий `go run . --config ...`
