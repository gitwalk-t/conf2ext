Выполни безопасный рефакторинг в `files-converter` без изменения внешнего поведения.

Сначала прочитай:
- `AGENTS.md`
- `.codex/context.md`
- `docs/architecture.md`
- `docs/conventions.md`

Правила:
- Предпочитай минимальные структурные изменения
- Не меняй семантику конфига, XML rewrite rules и conversion flow, если это не требуется задачей
- `internal/utils/xmlutil/change.go` — рискованный участок; выноси код только если граница очевидна, а проверка дешевая
- Обновляй docs только там, где действительно поменялась структура или зона ответственности

Проверка:
1. Подтверди, что поведение не меняется намеренно
2. Запусти `go build ./...`
3. Запусти `go test ./...`
4. Отдельно опиши остаточный риск, если рефакторинг хоть как-то затрагивал XML-логику
