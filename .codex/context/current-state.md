# Текущее состояние

Файл предназначен только для временного operational-контекста.

## Что сюда писать

- текущие расследования
- активные regression cases
- незавершенные refactoring notes
- временные workaround
- последние проблемные прогоны
- pending migration tasks

## Что сюда НЕ писать

- стабильные XML/classification rules
- постоянную терминологию
- архитектуру
- запуск orchestrator
- debugging cheatsheet

## Правило очистки

Если информация перестала быть актуальной:
- удалить ее
- либо перенести в:
  - `.codex/decisions.md`
  - `.codex/context/xml-rules.md`
  - `docs/debugging.md`
