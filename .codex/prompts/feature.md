Реализуй новую фичу в `files-converter` с минимальным риском для текущего поведения.

Сначала прочитай:
- `README.md`
- `AGENTS.md`
- `.codex/context.md`
- `.codex/handoff.md`
- `docs/architecture.md`
- `docs/conventions.md`

Ограничения:
- Предпочитай текущую структуру пакетов: `cmd` -> `pkg` -> `internal`
- Не добавляй зависимости без явной необходимости
- Если затрагивается поведение переписывания XML, обнови `docs/architecture.md` и допиши запись в `.codex/decisions.md`
- Учитывай совместимость с текущей JSON-схемой и устаревшими алиасами, если фича касается конфига

Порядок:
1. Найди минимальный ответственный модуль
2. Реализуй изменение с минимальным диффом
3. Добавь или обнови тесты, если для этого есть практичная точка входа; если нет — оставь точный TODO в `.codex/tasks.md`
4. Запусти `go build ./...` и `go test ./...`
5. Коротко опиши измененные файлы, assumptions и риски продолжения
